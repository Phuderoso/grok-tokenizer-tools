Grok Tokenizer Tools

Ferramentas locais para inspecionar os tokenizers públicos do Grok (Grok-1 e Grok-2).

O tokenizer não está exposto dentro da inferência. A forma correta é carregar o arquivo público localmente.

Arquivos públicos

  • Grok-1: tokenizer.model (SentencePiece, 131072 tokens)
  • Grok-2: tokenizer.tok.json (tiktoken-style, 131072 tokens)

Como usar localmente

pip install sentencepiece tiktoken
# Depois rode os scripts na pasta scripts/

Veja os scripts em scripts/ para exemplos de encode/decode.
